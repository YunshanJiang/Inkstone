# LXGW WenKai webfont

- Typeface: LXGW WenKai / 霞鹜文楷
- Webfont package: `lxgw-wenkai-webfont` 1.7.0
- Runtime stylesheet: `lxgwwenkai-regular.css`
- License: SIL Open Font License 1.1, see `OFL.txt`
- Source project: https://github.com/lxgw/LxgwWenKai

The WOFF2 files are Unicode subsets of the regular webfont and are loaded by
the stylesheet's `unicode-range` declarations. They are runtime copies; the
local `Assets/` and `design-assets/` directories are not referenced by the app.
